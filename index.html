Source & method

Data source

Daily open / high / low / close for the NIFTY 50 price index, built from two sources and reconciled against each other:

  • NSE official archives — nsearchives.nseindia.com/content/indices/ind_close_all_<DDMMYYYY>.csv, the exchange's own end-of-day index file. Authoritative, but only published from 2013 onward.
  • Yahoo Finance ^NSEI daily chart API for the bulk series, which begins 17 September 2007.

A stratified random sample of 195 trading days was checked against the official NSE file and matched to the paisa on every OHLC value. 24 genuine sessions absent from the bulk feed were recovered from the NSE archive, including the first trading day of 2016, 2018 and 2019 — days that would otherwise have produced the wrong starting price for those years.

Why the history starts in September 2007. No source I can reach publishes reliable daily NIFTY 50 closes before then — NSE's archive does not go back that far, and the index provider's bulk endpoint is closed. Rather than fill the gap with estimates, the record simply begins where the real data begins.

Calculation methodology

  • Annual return % = ((Ending close − Starting close) ÷ Starting close) × 100, where starting close is the close of the year's first actual trading day and ending close the close of its last actual trading day.
  • Calendar-year % uses the previous year's final close as the base. This is how published NIFTY annual-return tables are computed, which is why the two columns differ slightly.
  • Daily change % is measured against the previous trading session's close, carried across year boundaries, so the first day of each year has a real change figure.
  • Highest / lowest are closing prices, matching what the line chart plots.
  • Max drawdown is the deepest peak-to-trough fall in closing values inside the selected range.
  • Positive / negative / unchanged day counts use the same daily change figure.

A few honest caveats

  • Granularity is one row per trading session. Intraday or time-of-day history is not available for a span this long from any source I can reach, so the date pickers work in whole days.
  • A handful of Saturdays and Sundays appear in the data. These are real, officially settled NSE sessions — Diwali Muhurat trading and Union Budget Saturdays. They are kept so the record matches the exchange's own calendar.
  • Sessions before 2013 rest on the bulk feed alone; the NSE archive cannot corroborate them because those files do not exist.
  • This is a price index. It excludes dividends, so it understates what a NIFTY 50 investor actually earned.
  • Nothing here is investment advice — it is a record of what already happened.
